# 问卷调查

## 使用入口

管理端：WebUI → 问卷调查

填写端：个人中心 → 关于 → 问卷填写

单份问卷可通过 `https://公开访问域名/dashboard/surveys/8f3a01c9d2b7` 直接访问，管理端复制的填写链接附带 `?_wwv=9983&qq=1`

未登录时进入 QQ 登录流程，登录完成后直接返回该问卷。管理员从问卷链接进入时同样直接进入填写页，不显示工作台选择。账号未绑定时沿用个人中心的绑定提示

## 问卷与答卷

- 题型：单选、多选、文本
- 每道选择题 2–20 个选项
- 标题最多 120 字，说明最多 3000 字，题目最多 300 字，选项最多 200 字，文本回答最多 2000 字
- 草稿可自由编辑；已发布及已结束的问卷点击右上角「编辑」后可修订标题、说明、题干及选项文字，保存后重新锁定，取消编辑则还原本次修改
- 发布后禁止新增、删除、重排题目或选项，也不能修改标识、题型和必填规则；已有答卷继续关联原标识，显示修订后的文字
- 列表每份问卷右下角的三点菜单提供复制、复制填写链接、发布／停止收集／重新开放和删除操作，草稿不能复制填写链接
- 菜单中点击「复制为新问卷」，将已保存的标题、说明、题目及填写设置带入新建页，编辑后保存为独立草稿；生成新的问卷编号，不复制答卷、星标和收集状态
- 所有状态的问卷均可删除，删除时同时清理全部答卷和星标，操作不可恢复
- 已发布问卷可以停止收集，也可以重新开放；已提交答卷保留
- 默认每个统一账号每份问卷只能提交一次，重复请求返回已有答卷
- 开启「允许重复填写」后，同一账号可不限次数提交，每次生成独立答卷；填写页显示最近一次答卷，通过「再次填写」开始新答卷
- 重复填写按统一账号及问卷进行内存频控，滚动一小时内最多成功提交 5 份，首次填写也计入；请求重试和提交失败不占次数，进程重启后清零
- 所有状态均可调整重复填写设置，关闭后保留全部历史答卷，不再接受同一账号的新答卷；停止收集期间不能再次填写
- 填写端提交前显示确认弹窗，取消后保留填写内容，确认后才发送提交请求
- 可设置提交奖励，默认 0 金粒；每个账号每份问卷仅首次成功提交时发放，再次填写不重复领奖，修改奖励不补发历史答卷
- 列表可见性默认开启，草稿、收集中及已结束的问卷均可调整；隐藏只影响填写端列表，已发布问卷仍可通过链接访问
- 所有状态均可置顶或取消置顶，管理端与填写端均在分页前按置顶优先、创建顺序倒序排列；置顶不改变可见性，隐藏问卷和草稿不会因此出现在填写端列表
- 用户只能查看自己的答卷，管理端可以分页查看全部答卷
- 当前版本为实名问卷，管理端显示提交时的用户名与用户平台 ID
- 答卷列表每页 20 份，仅显示提交人、提交时间和星标；点击条目打开详情弹窗，可切换上一份、下一份或跳转指定序号
- 管理员可手动添加或取消答卷星标，标记由管理端共享，不影响用户填写状态
- 「仅看星标」筛选同时作用于列表总数、分页、详情序号及上一份／下一份；筛选期间取消星标会刷新列表，若正在查看该答卷则关闭详情

数据分别保存到 `surveys` 和 `survey_responses`，启动时创建表，不修改原有账号表

奖励金额保存在 `surveys.reward_gold`，列表可见性保存在 `surveys.visible`，实际发放金额保存在 `survey_responses.reward_gold`。答卷、金粒余额和来源日志在同一事务中写入，任一步失败则全部回滚。奖励写入当前登录用户的金粒账户，来源标识为 `survey`；删除问卷不撤回已发奖励

置顶状态保存在 `surveys.pinned`，默认 `false`

星标保存为 `survey_responses.starred`，默认未标记

重复填写设置保存在 `surveys.repeatable`，默认 `false`。`survey_responses.request_id` 保存提交请求标识，在同一问卷、同一账号内唯一，用于处理网络重试

问卷对外使用 12 位随机短编号，例如 `8f3a01c9d2b7`，列表、详情及填写链接中的 `id` 均为字符串。编号由安全随机数生成，数据库唯一约束处理碰撞，不由自增数字截取或转换

数字主键仅用于数据库内部关联，填写链接使用 `public_id`。启动时仅创建不存在的表，已有表不再执行历史扩表和数据迁移

## 接口

响应使用项目的 `Result` 格式，`code = 0` 表示成功，业务数据位于 `data`

管理接口位于 `/webui/api/surveys`，沿用 WebUI 开关、QQ 登录会话、ADMIN / OWNER 身份及写请求来源检查

| 方法 | 路径后缀 | 用途 |
| --- | --- | --- |
| GET | `?offset=0` | 问卷列表，每页最多 50 份 |
| POST | 无 | 创建草稿 |
| GET | `/{id}` | 问卷详情 |
| PUT | `/{id}` | 修改草稿或修订已发布问卷文字 |
| DELETE | `/{id}` | 删除问卷及全部答卷 |
| POST | `/{id}/status` | 发布或关闭 |
| PUT | `/{id}/settings` | 修改奖励、列表可见性、置顶状态及重复填写设置，所有状态均可操作 |
| GET | `/{id}/responses?page=1&snapshot=0` | 按提交 ID 倒序读取答卷摘要，每页 20 份，不包含答案 |
| GET | `/{id}/responses/at/{position}?snapshot=100` | 获取指定序号的完整答卷，序号从 1 开始 |
| PUT | `/{id}/responses/{responseId}/star` | 设置星标，请求体为 `{"starred":true}` 或 `{"starred":false}` |

答卷列表返回 `items`、`total`、`snapshot`、`page`、`pageSize`，摘要包含 `id`、`userOpenId`、`username`、`submittedAt`、`starred`

首次读取传 `snapshot=0` 或省略，服务端返回本次浏览的答卷 ID 上界。分页和详情查询携带该值，新提交的答卷不会改变当前序号；刷新列表时重新传 `snapshot=0`。该参数不生成数据库快照或额外记录

答卷列表及详情接口均支持 `starredOnly=true`，省略或传 `false` 表示全部答卷，其他取值返回 `74002`。筛选在数据库分页前执行，`total` 与 `position` 按当前筛选计算，分页超出末页时返回末页。星标状态实时读取，变更星标可能改变筛选内的序号，`snapshot` 只限制新答卷加入

答卷详情返回 `answer`、`starred`、`position`、`total`、`snapshot`，`answer` 包含账号标识、提交时间和 `answers`。星标接口使用答卷自身的 `id`，不使用序号；服务端校验答卷属于路径指定的问卷

创建请求：

```json
{
  "title": "机器人使用体验",
  "description": "填写你的使用情况",
  "rewardGold": 20,
  "visible": true,
  "pinned": false,
  "repeatable": false,
  "questions": [
    {
      "id": "q1",
      "type": "SINGLE",
      "title": "常用功能",
      "required": true,
      "options": [
        {"id": "a", "label": "查询"},
        {"id": "b", "label": "小游戏"}
      ]
    }
  ]
}
```

题型取值为 `SINGLE`、`MULTIPLE`、`TEXT`；文本题的 `options` 为 `[]`。题目与选项 ID 为 1–40 位英文字母、数字、下划线或连字符，分别要求问卷内、题目内唯一

修改题目请求为 `{"revision": 1, "definition": {"title": "标题", "description": "说明", "questions": []}}`，`questions` 应填写完整题目。状态请求为 `{"revision": 1, "status": "PUBLISHED"}` 或 `{"revision": 2, "status": "CLOSED"}`，版本号从详情读取

设置请求为 `{"revision": 2, "rewardGold": 20, "visible": false, "pinned": true, "repeatable": true}`，五个字段均需提供，成功返回更新后的问卷。`rewardGold` 为非负整数，0 表示不奖励；创建时可省略，默认为 0。`visible`、`pinned`、`repeatable` 为布尔值，创建时可省略，分别默认为 `true`、`false`、`false`

修改题目、状态或设置均递增版本号，旧版本的新提交返回 `74005`，需要重新读取问卷。列表与详情返回当前 `rewardGold`、`visible`、`pinned`、`repeatable`；答卷中的 `rewardGold` 为当次实际发放金额

填写接口位于 `/atrimeow/profile/api/surveys`，必须携带当前个人中心页面的 `Authorization: Bearer <token>`，账号身份从会话取得

| 方法 | 路径后缀 | 用途 |
| --- | --- | --- |
| GET | `?offset=0` | 列表可见且已发布或已关闭的问卷，包含本人是否已提交 |
| GET | `/{id}` | 问卷与本人最近一次答卷，草稿不可见 |
| POST | `/{id}/responses` | 提交答卷 |

提交请求：

```json
{
  "revision": 2,
  "requestId": "44b3b03d-31a5-443b-97a0-480bc82d47d7",
  "answers": {"q1": ["a"]}
}
```

选择题提交选项 ID 数组；文本题提交单元素字符串数组；未填写的选填题可省略或传空数组。接口校验必填项、选项范围、未知题目、重复选项和文本长度

`requestId` 使用小写、带连字符的 UUID，允许重复填写的问卷必须提供。开始新答卷时生成新值，同一次提交的网络重试必须复用原值；服务端返回该标识对应的已保存答卷，不重复新增或发奖，即使问卷之后停止收集也可重试。普通问卷可省略此字段，仍按账号返回已有答卷

| 业务码 | 含义 |
| --- | --- |
| 74001 | 问卷不存在或尚未发布 |
| 74002 | 问卷或答案格式无效 |
| 74003 | 问卷已停止收集 |
| 74004 | 已发布的问卷仅可修改文字，不可修改题目结构 |
| 74005 | 问卷版本或状态已更新，需要刷新 |
| 74006 | 答卷不存在或序号超出范围 |
| 74007 | 重复填写超过每小时 5 份限制，HTTP 状态为 429 |

## 登录返回

`POST /dashboard/api/auth/start` 增加可选 `survey` 字段，仅接受 `list` 或12 位小写十六进制问卷编号。该字段存入服务端一次性 OAuth 状态，回调校验 state 后生成固定站内路径，不接受外部返回 URL
