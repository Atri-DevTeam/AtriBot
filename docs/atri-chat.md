# 亚托莉群聊

开启群功能 `atri_chat` 后，普通群消息会进入本群共享上下文。发送 `-内容` 才会触发亚托莉回复；机器人消息不会记录或触发回复。支持引用消息以及消息前的 QQ 提及。

- `-h`、`-help`、`-帮助`：查看帮助。
- `-c`：清除本群近期消息和经历摘要，群主、群管理员或机器人管理员可以使用。

每条记录保留用户 ID、昵称、消息 ID、引用关系和时间。同名成员与不同群的记忆彼此区分。称呼偏好等信息通过近期上下文及经历摘要保留。

## JSON 文件

- `data/atri-chat/persona.json`：`characterPrompt` 是角色设定，`groupPrompt` 是群聊规则。修改后下一次聊天生效。文件不存在时从内置的 `atri-chat/persona.json` 初始化；已有文件不会覆盖。
- `data/atri-chat/groups/<群号>.json`：本群近期消息和经历摘要。群号不是数字时使用其 SHA-256 作为文件名，原群 ID 保留在 JSON 内。

新增持久化数据全部存放在上述 JSON 中，不使用数据库。文件通过临时 JSON 和替换写入；读取失败或文件损坏时保留原文件并记录错误。

每次回复最多选取最近 20 条消息及约 6000 字符的消息记录，另附经历摘要、当前消息和可找到的引用消息。当前消息只发送一次。输入消息最多保留 1200 字符。

记录超过 48 条时，回复完成、群聊空闲 8 秒后，会在后台额外调用一次原有 AI 接口整理较早记录，至少保留最近 24 条。只有摘要返回有效内容且成功写入 JSON 后才删除对应旧记录；失败时保留旧记录等待下次整理。清理期间本群仍可继续聊天，清除记忆后旧摘要不会重新写入。只有普通消息、未触发聊天时不会调用 AI，因此原始记录可能持续增长。日志会分别记录每次回复的上层准备、模型耗时和输入长度，不记录聊天正文。

群聊只调用现有 `AiService.askWithSystemPrompt`，使用 `PLAN_2`。历史身份由业务层的 JSON 字段表达，底层请求协议、模型配置和默认提示词保持原样。

默认人设采用提供的亚托莉资料，区分互斥故事路线，支持简短中文、括号动作与表情；不加入取消安全限制或配合未成年角色色情内容的规则。
